# Preliminary tests
This directory contains source code and results of tests ran on the performance of prior passive client identification tools - Joy, Zardaxt, and p0f. The experiements test (1) how many clients in our captured traffic (which we do not reveal) from a large campus network appear in their databases and (2) whether the three tools agree on the classification results. Our results show that only 6% of the clients appear in all three databases and even then, the tools rarely agree on what the clients are.

### For more results, see Table 1 of our paper: https://arxiv.org/pdf/2410.02040.
